# VibeFrame ✨

 Create. Feel. Frame.

A simple interactive web application that lets users create a personalized mood frame based on their mood, theme, name, and quote.

## Features ✨

* 🎭 Mood selection
* 🎨 Multiple themes
* ✍️ Custom quote
* 👤 Personalized name
* 🎲 Random vibe generator
* 📥 Download frame as PNG
* 📱 Responsive design

## Tech Stack 🛠️

* HTML5
* CSS3
* JavaScript
* html2canvas
* Git & GitHub
* GitHub Pages
